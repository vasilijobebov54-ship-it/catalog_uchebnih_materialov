# Каталог учебных материалов

Учебный проект группы 2ИП-9-25. Участники: Силин Матвей, Сидоров Артём, Петрухин Егор.

## Второй спринт

Добавлен графический интерфейс на **Tkinter** с кнопками, таблицей, шрифтами и стилями. Данные хранятся в **SQLite** (`materials.db`). При первом запуске, если есть `materials.json`, программа пытается импортировать данные; иначе создаёт примеры.

Функции: просмотр списка, поиск по названию, добавление, изменение, удаление, а также **три новых возможности**: сортировка по алфавиту, фильтрация по типу, статистика каталога.

## Запуск

Нужен Python 3 с Tkinter и SQLite.

```bash
python gui.py
```

Для Linux при отсутствии Tkinter установите пакет `python3-tk` через пакетный менеджер системы. Библиотека SQLite обычно входит в стандартную поставку Python.

Кнопки управления находятся внизу окна. Для редактирования и удаления сначала выберите строку таблицы.

## Файлы

- `gui.py` — графический интерфейс.
- `catalog_db.py` — SQL-запросы и работа с базой.
- `main.py` — консольная версия, работающая с общей базой SQLite.
- `materials.db` — создаётся при первом запуске.

## Организация работы

Во втором спринте команда меняется ролями; актуальные роли и статус задач фиксируются в МосТрекере. Старый спринт нужно завершить и начать новый в трекере.

## Обновление: общая база для консоли и графического интерфейса

После доработки `main.py` и `gui.py` используют **одну и ту же базу SQLite** — `materials.db`. Доступ к базе выполняется через модуль `catalog_db.py`. Поэтому добавленные в графическом интерфейсе материалы видны в консоли (пункт **1 — Все материалы**), и наоборот. Для обеих версий нужен общий каталог проекта с одним файлом базы.

### Запуск двух версий

Из папки проекта запустите нужную команду:

```bash
python3 gui.py   # графическое приложение
python3 main.py  # консольное меню
```

На Windows вместо `python3` можно использовать `python`.

Консольное меню: **1** — просмотр всех материалов; **2** — поиск по ID; **3** — поиск по названию; **4** — добавление; **5** — редактирование; **6** — удаление; **0** — выход.

### Прикрепление учебных файлов

В графическом приложении кнопка **«Загрузить файл»** открывает выбор документа. Пользователь указывает название и тип материала. Копия выбранного файла сохраняется в папке `uploads/`, а запись с путём к файлу — в `materials.db`. Чтобы открыть прикреплённый документ, выберите материал в таблице и нажмите **«Открыть файл»**.

Кнопка **«Добавить запись»** создаёт материал **без прикреплённого файла**. Поиск, сортировка по алфавиту, фильтрация по типу, статистика, изменение и удаление записей доступны через графический интерфейс.

**Важно:** база `materials.db` и файлы из `uploads/` хранятся **локально на компьютере**. GitHub и МосХаб не синхронизируют их автоматически. Для переноса пользовательских материалов на другой компьютер потребуется отдельно перенести файл базы и папку с вложениями. Удаление записи из каталога не удаляет физическую копию прикреплённого файла из папки `uploads/`.

### Актуальная структура проекта

- `main.py` — консольный интерфейс, подключённый к общей базе SQLite.
- `gui.py` — графический интерфейс Tkinter.
- `catalog_db.py` — операции с SQLite и прикреплёнными файлами.
- `materials.db` — локальная база данных; создаётся автоматически при запуске.
- `uploads/` — локальная папка с копиями добавленных пользователем файлов.
- `materials.json` — необязательный файл для первоначального импорта старых записей в новую базу.
