# Каталог учебных материалов

Учебный проект группы 2ИП-9-25. Участники: Силин Матвей, Сидоров Артём, Петрухин Егор.

## Второй спринт

Добавлен графический интерфейс на **Tkinter** с кнопками, таблицей, шрифтами и стилями. Данные хранятся в **SQLite** (`materials.db`). При первом запуске, если есть `materials.json`, программа пытается импортировать данные; иначе создаёт примеры.

Функции: просмотр списка, поиск по названию, добавление, изменение, удаление, а также **три новых возможности**: сортировка по алфавиту, фильтрация по типу, статистика каталога.

## Запуск

Нужен Python 3 с Tkinter и SQLite.

```bash
python gui.py
```

Для Linux при отсутствии Tkinter установите пакет `python3-tk` через пакетный менеджер системы. Библиотека SQLite обычно входит в стандартную поставку Python.

Кнопки управления находятся внизу окна. Для редактирования и удаления сначала выберите строку таблицы.

## Файлы

- `gui.py` — графический интерфейс.
- `catalog_db.py` — SQL-запросы и работа с базой.
- `main.py` — предыдущая консольная версия (не изменена).
- `materials.db` — создаётся при первом запуске.

## Организация работы

Во втором спринте команда меняется ролями; актуальные роли и статус задач фиксируются в МосТрекере. Старый спринт нужно завершить и начать новый в трекере.
