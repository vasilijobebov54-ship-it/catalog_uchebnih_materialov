# Требования и структура проекта

## Источник

В предоставленном пользователем README проекта `study-materials-catalog`
на МосХабе указана тема №3:
«Консольный каталог учебных материалов (поиск книг/методичек по ID)».
Остальной текст README — стандартные рекомендации по оформлению репозитория;
дополнительные функции приложения в нём не заданы.

## Основной функционал

- Работа с каталогом учебных материалов через консоль.
- Поиск книги или методички по ID.
- Вывод пользователю результата поиска.

Язык Python указан в сводке предыдущего обсуждения проекта.
По условиям текущей работы код должен быть простым и объяснимым на защите,
а изменения — небольшими, с отдельными короткими коммитами.

## Согласованные решения для первой версии

- ID — целое положительное число.
- Запись содержит название и тип: книга или методичка.
- Несколько учебных примеров хранятся прямо в коде в словаре по ID.
- За один запуск программа запрашивает один ID и выводит сведения
  о материале или сообщение «Материал не найден».
- Если введено не целое положительное число, выводится сообщение об ошибке.

Названия материалов в коде — демонстрационные примеры.

## Что ещё нужно уточнить

- Необходимость сохранения данных между запусками.
- Нужны ли просмотр всего каталога, добавление, редактирование и удаление.

Эти функции пока не включены в обязательные требования.

## Текущая структура и запуск

- `main.py` — минимальный поиск по ID.
- `docs/requirements.md` — требования и описание текущей версии.

Для запуска нужен Python 3. В папке проекта выполните:

```text
python main.py
```

Примеры проверки: ID `1` — книга «Основы Python»;
ID `2` — методичка; ID `99` — материал не найден;
`abc`, пустой ввод, `0`, `-1` и `1.5` — сообщение об ошибке.
