# Консольный каталог учебных материалов

Тема №3: «Консольный каталог учебных материалов (поиск книг/методичек по ID)».
Язык программирования — Python.

## Назначение

Поиск учебных материалов по ID через консоль и вывод информации о найденном
материале.

## Данные

- ID — целое положительное число.
- Название материала.
- Тип — книга или методичка.

В текущей версии каталог хранится в словаре в `main.py`.
Он содержит три демонстрационные записи. Сохранения в файл нет.

## Работа программы

1. Пользователь вводит ID материала.
2. Программа проверяет, что введено целое положительное число.
3. Если материал найден, выводятся его ID, название и тип.
4. Если такого ID нет, выводится «Материал не найден».

При неправильном вводе выводится сообщение об ошибке.
После одного запроса программа завершает работу.

## Структура проекта

- `main.py` — каталог, ввод ID, поиск и вывод результата.
- `docs/requirements.md` — описание требований и текущей версии.

## Запуск

Требуется Python 3. В папке проекта выполните:

```text
python main.py
```

## Проверка

| Ввод | Ожидаемый результат |
| --- | --- |
| `1` | Книга «Основы Python» |
| `2` | Методичка «Практические задания по Python» |
| `3` | Книга «Основы алгоритмизации» |
| `99` | Материал не найден |
| `abc`, пустой ввод, `0`, `-1`, `1.5` | Сообщение об ошибке |

## Открытые вопросы

Необходимость сохранения данных, просмотра всего каталога, добавления,
редактирования и удаления материалов пока не определена.
